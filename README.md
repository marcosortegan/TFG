Técnicas numéricas para la optimización no lineal en problemas variacionales

Trabajo sobre métodos numéricos para resolver problemas variacionales, es decir, problemas en los que lo que se busca no es un número sino una función que minimiza (o maximiza) un funcional. Este tipo de problemas sale de forma natural al estudiar ecuaciones diferenciales, pero también en campos bastante distintos como el tratamiento de imágenes o las finanzas.

La idea del trabajo es estudiar, analizar y aplicar distintas técnicas de optimización a algunos de estos problemas, centrándonos sobre todo en el caso no lineal. Para ello se usan dos familias de métodos: algoritmos iterativos de aproximación y métodos de búsqueda aleatoria.
